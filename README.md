# Telegram Musiqa Boti (@cheater_000bot)

Ushbu bot Telegram foydalanuvchilariga istalgan musiqani qidirish, natijalarni ko'rish va to'g'ridan-to'g'ri MP3 formatida yuklab olish imkonini beradi.

### Asosiy xususiyatlari:
- **Cheksiz musiqa bazasi (10 000+ emas, millionlab taronalar):** Dunyodagi barcha o'zbek, rus, ingliz va xorijiy qo'shiqlarni qidirib topadi.
- **Tashqi API kalit shart emas:** Dastur hech qanday pulli yoki maxsus API kalitlarsiz to'g'ridan-to'g'ri ishlaydi.
- **Tezkor yuklash:** Musiqani MP3 (192 kbps) audio formatga o'tkazib, ijrochi va nomini chiroyli yorliqlar bilan yuboradi.
- **YouTube havolalari:** To'g'ridan-to'g'ri YouTube yoki YouTube Music havolalarini ham MP3 holatida yuklab beradi.
- **Xotirani tozalash:** Yuklangan fayllar foydalanuvchiga yuborilgach, kompyuter xotirasini band qilmaslik uchun avtomatik o'chiriladi.

### Loyiha fayllari:
- `bot.py` - Botning asosiy boshqaruvchi kodi (Aiogram 3).
- `music_service.py` - Musiqa qidirish va yuklab olish xizmati.
- `keyboards.py` - Telegram interaktiv inline tugmalari.
- `config.py` va `.env` - Bot tokeni va sozlamalari.
- `run.bat` - Botni bitta klik bilan ishga tushirish fayli.

### Qanday ishga tushiriladi?
`run.bat` fayliga sichqoncha bilan ikki marta bosishingiz kifoya!
